# Security policy

Please do not report a vulnerability in a public GitHub issue, discussion, or
pull request.

Use GitHub's private vulnerability reporting for this repository:

<https://github.com/hyfens-hq/hyfens/security/advisories/new>

Include the affected version or commit, the smallest reproducible example,
the impact, and any suggested mitigation. Do not include passwords, private
keys, session tokens, or customer data in the initial report. If private
reporting is unavailable, contact the maintainers through a private channel
before sharing sensitive details publicly.

The latest tagged release and the `main` branch are the supported reporting
targets. Other revisions may be reviewed at the maintainers' discretion.

The project will acknowledge reports when practical, coordinate a fix and
disclosure timeline with the reporter, and credit the reporter when they give
permission. No response-time or bounty commitment is made by this document.
